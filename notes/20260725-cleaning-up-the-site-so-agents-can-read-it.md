This week I cleaned up the site to enable agents to crawl it more efficiently.

My site analytics now hand themselves to an AI agent that writes its own weekly digest. Then I found half the site was quietly sending no data. Pretty dashboard, no numbers. Fixed that first. An agent is only as honest as what it reads.

Added a healthcare category in ESG Tracker. Did randomised checks on the numbers — means manually checking numbers against actual sustainability reports. I've built stringent checks into the agent, but it's still good to do random checks. https://www.pris.la/sustainability/report_comparison/

Added media uploads to the blog so I can add photos and videos. I've not tested that yet, though, so pure text for now.
